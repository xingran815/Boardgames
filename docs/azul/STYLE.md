# Azul explainers: shared visual style

All Azul outputs (colour PDF, HTML, videos) use these **original** tile designs. Do not copy the game's
printed tile art, logo or board artwork. Use flat, simple shapes that read well when small and in
black-and-white print.

| Colour | Letter | Fill | Mark (white or dark, centred) |
|---|---|---|---|
| blue   | B | #2F6FB5 | small circle |
| yellow | Y | #E8B730 | four-point star |
| red    | R | #C8423A | diamond |
| black  | K | #2A2D34 | plus sign |
| white  | W | #EEF1F4 (with #9AA4B1 outline) | small square ring |

- Every tile also shows its letter (B Y R K W) in a corner or in place of the mark at very small sizes, so colour is never the only cue.
- Starting player marker: a light tile with the numeral "1".
- Wall spaces not yet tiled: a faint version of the colour, at about 25% opacity, with the same mark.
- Factory display: a plain circle in a warm tan colour (#D9B38C) with a darker rim.
- Floor line values print under each space: −1 −1 −2 −2 −2 −3 −3.
- Words: use the names in docs/azul/manual.md exactly (factory display, centre of the table, pattern line, wall, floor line, box lid, starting player marker, score track).
